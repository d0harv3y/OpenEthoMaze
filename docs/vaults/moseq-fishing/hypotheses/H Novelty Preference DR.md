**Parent:** [[T1 Recognition NOR]].
**Status:** answered null (DR does not separate condition). #clock-portable

**Question:** Does `condition` (`noSD` / `GHSD` / `RBSD`) change novel preference (DR) at `NOR_TX`?

**Design:** independent groups within sex → Kruskal–Wallis on DR.

**Computed (object-prox consensus):** miss (F p≈0.34; M p≈0.96). Medians stay high in all arms (~0.35–0.51).

**Verdict:** no evidence SD arms shift the sold memory scalar. Null on DR×condition ≠ proof circuits are untouched — only that this DR definition does not separate arms.

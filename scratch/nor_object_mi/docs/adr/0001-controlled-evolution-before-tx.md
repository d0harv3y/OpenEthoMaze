# Controlled evolution before tx, noSD Wilcoxon within sex

Pooled-tx Wilcoxon on phase or condition Δ mixes control-arm extinguish with treated trajectories, which makes later tx tests on novelty steps across BL→TX→REC hard to interpret. The catalog therefore reads snapshots and per-arm, per-sex evolution first; inferential evolution is `noSD` within sex; GHSD/RBSD stay descriptive overlays until the rank tx lattice.

## Considered options

- Txs pooled as evolution primary (rejected: hides extinguish).
- `noSD` only, no other-arm D (rejected: you cannot see persist vs fade by arm).
- Each tx as D, `noSD` I, split by sex (accepted).

## Language

**Protocol check**:
A face-check that this NOR dataset shows presence and novel preference as intended.
_Avoid_: validation (when you mean this face-check)

**Controlled evolution**:
How a scalar or composition moves along a pairing axis with the other axis held, described per tx and sex, with inferential tests on `noSD` within sex.
_Avoid_: txs-pooled Wilcoxon as the evolution primary

**Rank primary**:
Wilcoxon / Kruskal / Spearman as the claimed error model for this narrative.
_Avoid_: calling t / Welch / Pearson a different D vs I split

**Mean/interval cousin**:
The same design strip with t / Welch / Pearson (`protocol_prologue`, `tx_on_paired_delta_parametric`).
_Avoid_: parametric as primary, rank vs mean as descriptive vs inferential

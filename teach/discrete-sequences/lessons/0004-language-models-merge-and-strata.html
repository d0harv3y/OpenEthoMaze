From n-grams to language models

Lesson 0002 introduced n-grams as frequent symbol patterns. A language model (LM) assigns probabilities to those sequences: how likely is the next syllable bout given recent context?

A bigram model approximates:

Bigram (Markov order 1 at bout grain) \(P(s_t \mid s_{t-1}, s_{t-2}, \ldots) \approx P(s_t \mid s_{t-1})\)

Estimate from counts: \(P(7 \mid 3) = \mathrm{Count}(3,7) / \mathrm{Count}(3)\). Same Markov idea as Jurafsky Ch. 3 — applied here to syllable-id bouts, not words. Jurafsky & Martin, §3.1–3.2

Perplexity summarizes how “surprised” the model is by a held-out stream (lower = transitions look more predictable). Useful for comparing streams or refits — not for naming behaviors by itself.

Merge & language-model thinking

When should you merge syllables 3 and 7? LM thinking suggests:

  • Occupancy: if 3 and 7 are rare splits of one kinematic class, merging raises combined occupancy and simplifies tables.
  • Transitions: if \(P(\cdot \mid 3)\) and \(P(\cdot \mid 7)\) look similar, merge may preserve bigram structure better than keeping both.
  • Perplexity: on a validation set, a merged stream should not inflate surprise unless you removed real structure.

Current merge is manual (syllable_groups.yaml with groups: [[1,3,5], …]) — you decide groups after grid review, not an auto-LM. After merge: write results_merged.h5, then re-run compile → mine → summarize so occupancy and grammar candidates reflect the new alphabet.

Occupancy over strata (tx, sex, strain, session)

Occupancy = fraction of phase time (or bout count) spent in each label, grouped by manifest strata. This answers: “Did tg females spend more time in syllable 7 during run?”

Shipped today for behavior tokens / ethology (Stage III):

CLI uv run maze-summarize-behavior-tokens --grain token --phase run …
uv run maze-summarize-behavior-tokens --grain ethology --phase all …

Outputs under stage_iii/…/summaries/: occupancy.csv (pooled strata), occupancy_by_session.csv, transitions.csv (bout-to-bout — a discrete first-order chain).

Strata keys: (session, tx, sex, strain) from the manifest (behavior_token_summarize.py). Compare rows with the same label across strata; session column empty when pooled, populated for session trends.

Did merge/refit break structure? Occupancy can look stable while order shifts Perplexity + transition CSV before/after

For raw syllable strata (pre-grammar): aggregate stage_ii/bout_features.csv by raw_syllable_id and manifest fields, or count frames in results.h5 after compile alignment. After merge or refit, always recompute — ids are fit-local.

Neural LMs (transformers) — where they fit later

Transformer LMs learn long-context predictions from huge text. Analogies for behavior: discover merge candidates from embedding similarity, or detect distributional shift between cohorts. Your pipeline does not require them for v1: n-gram grammar + occupancy/transition tables are interpretable and match shipped CLIs. Treat neural models as optional upgrades after discrete baselines behave sensibly on overlays.

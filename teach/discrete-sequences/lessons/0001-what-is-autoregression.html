What is autoregression?

The one-sentence idea

An autoregressive model says the value now is a function of values you already observed in the same series, plus fresh random noise.

“Auto” = self. “Regressive” = regression — predicting a variable from predictors. Here the predictors are past versions of the same variable.

Appendix tie-in
Option D (maze-fit-bout-arhmm) uses AR on continuous bout features inside hidden states — not syllable-id n-grams. For syllables→words, see Lesson 0002.

AR(1): the smallest nontrivial model

Order 1 means one lag. Write the series as \(Y_t\) (value at time \(t\)) and noise as \(\varepsilon_t\) (white noise — unpredictable shocks, mean zero):

AR(1) \(Y_t = \phi\, Y_{t-1} + \varepsilon_t\)

Read it aloud: “Today equals phi times yesterday, plus a new shock.” If \(\phi = 0.8\), yesterday’s value is echoed into today but damped; shocks still nudge the path. If \(|\phi| \ge 1\) without extra structure, the echo never dies — the series is non-stationary (variance blows up). For AR(1), stationarity needs \(|\phi| < 1\).

AR(p): look back p steps

General order \(p\) keeps \(p\) lags as linear predictors:

AR(p) \(Y_t = \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + \cdots + \phi_p Y_{t-p} + \varepsilon_t\)

\(p\) is a hyperparameter: how far back direct linear dependence runs. In your bout AR-HMM, nlags plays the same role for latent dynamics inside each hidden state — higher order → richer short-term kinematics, but more matrices to estimate and more ways for numerics to go wrong.

How this differs from ordinary regression

Linear regression: \(Y\) from fixed covariates \(X\). AR: covariates are past \(Y\). That creates serial correlation by construction — today correlates with yesterday because yesterday is literally in the equation. Diagnostics (ACF, PACF) exist precisely because independence assumptions from vanilla regression fail.

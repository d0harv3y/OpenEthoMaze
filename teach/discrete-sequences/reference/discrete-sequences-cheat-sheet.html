Pipeline (Option A)

  1. Mine n-grams → candidate_sequences.csv
  2. Curate names + anchor_bucket + overlay review
  3. Build → grammar_rules.json
  4. Export → producers/syllable_grammar/

Apply algorithm

Greedy scan index i = 0 … n-1:

  1. Sort rules by (−pattern length, −priority, pattern)
  2. At i, first rule whose pattern matches ids[i:i+len] wins
  3. Label span; set i += len(pattern)
  4. If no match, i += 1 (bout stays unlabeled)
